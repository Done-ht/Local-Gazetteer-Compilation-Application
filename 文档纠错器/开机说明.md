# 文档纠错器（服务器版）· 开机说明

> 中文文档 AI 校对工具（功能同本地版），但做成**浏览器模式**：
> 服务跑在 Windows 电脑上，使用者用浏览器访问即可——电脑、平板、手机（含**鸿蒙系统**）都能用，不用装软件。

## 怎么开机

1. 双击本目录下的 **`dist\文档纠错器-服务器.exe`**（约 36MB）；
2. 按提示输入监听端口（**直接回车用默认 8000**）；
3. 浏览器打开**启动窗口显示的网址**（直接回车时默认 `http://127.0.0.1:8000/`，你改了端口就以窗口显示为准）；
4. 首次启动：控制台会**一次性打印管理员 token**，用它登录；
   - 之后在页面「用户管理」里创建其他用户（每人一个 token），各人资料互相隔离；
5. 关闭那个黑色窗口服务即停止。

## 局域网 / 鸿蒙设备使用

- 启动时加参数 `--host 0.0.0.0`：`文档纠错器-服务器.exe --host 0.0.0.0`
- 同网络内的电脑 / 鸿蒙平板 / 手机，浏览器打开**启动窗口显示的局域网地址**（`http://你的电脑IP:端口/`）即可使用
- 注意 Windows 防火墙需放行 8000 端口
