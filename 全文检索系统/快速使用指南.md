# 全文检索系统 · 快速使用指南

> 本文档写给**拿到这套文件、第一次使用的人**。照做即可用起来，不需要会编程。

---

## 一、这套文件是什么

一套**本地知识库检索系统**（也叫"全文检索系统"）的 Windows 版成品包。它可以在你自己的电脑上：
- 把 PDF / Word / txt / md 文档建成资料库；
- 用**关键词检索**或**语义检索**（按意思找，支持模糊语义）查找资料；
- 可选接入 DeepSeek 大模型，实现**智能问答**（AI 结合库内资料回答）。

所有资料和索引都存在本机，纯本地运行，不需要联网（联网只在用 AI 问答时才会用到）。

---

## 二、运行环境要求（先看这里）

| 项目 | 要求 |
|------|------|
| **操作系统** | **仅 Windows 64 位**（Windows 10 / 11 64 位均可）。不支持 32 位系统，不支持 Mac / Linux。 |
| 内存 | 建议 8GB 及以上（语义检索要加载向量模型，4GB 会吃力）。 |
| 硬盘空间 | 程序本体约 1.5GB，另需空间存放你的资料库（按资料量增长）。 |
| 显卡 | 不需要独立显卡，普通核显即可（CPU 跑语义模型）。 |
| 网络 | 仅"智能问答"需要联网（DeepSeek 接口）；纯检索完全离线。 |
| 浏览器 | Chrome / Edge / 360 等任意现代浏览器。 |

## 三、快速启动（怎么"开机"）

拿到的是一个文件夹（里面至少有以下 3 个东西，**缺一不可**）：

```
全文检索系统/
├── manager.exe          ← 启动器（推荐双击这个）
├── 全文检索系统.exe      ← 主程序
├── _internal/           ← 运行库（约 1.3GB，千万别删）
└── data/                ← 你的资料库数据（备份它就是备份全部资料）
```

### 方式一（推荐）：双击 manager.exe

1. 双击 `manager.exe`，会弹出黑色命令行窗口。
2. 按提示输入选择：
   - 输入 `1` 回车 → **本机使用**（只有自己电脑能访问）；
   - 输入 `2` 回车 → **服务器模式**（局域网内其他人也能访问）。
3. 首次启动需要初始化语义模型，**约 5~10 分钟**，期间窗口显示"正在启动服务"，耐心等待。
4. 看到 `访问地址：http://127.0.0.1:20000` 后，用浏览器打开这个地址即可进入系统。

> ⚠️ 重要：这个黑色窗口**必须保持打开**。关掉它服务就停了。

### 方式二：直接双击主程序

1. 双击 `全文检索系统.exe`。
2. 依次提示"数据目录""监听端口"时，**直接按回车**用默认值。
3. 浏览器打开**启动窗口显示的访问地址**（默认 `http://127.0.0.1:20000/`，端口被占用会自动后移，以窗口显示为准）。

### 方式三：命令行启动（给会用命令行的人）

```bat
cd 全文检索系统
全文检索系统.exe --no-dialog
:: 或指定端口：全文检索系统.exe --no-dialog --port 20000
```

## 四、第一次使用：配置 AI（可选）

- 打开页面后，进入 **「设置」** 页；
- 填入 **DeepSeek API Key**（需在 DeepSeek 官网申请，付费额度自理）；
- 保存后即可使用「智能问答 / 智能体工作流」模式。
- 不填 Key 也能正常使用**关键词检索、语义检索**功能，只是 AI 问答用不了。

---

## 五、基本使用流程

1. **新建资料库**：页面上点「新建库」，起个名字（如"郎溪县志"）。
2. **导入文档**：进入库，上传或选择 PDF / docx / txt / md 文件（可整目录导入），等进度条完成。
3. **检索**：输入关键词搜索；或点"语义检索"按意思找。支持 `刘备 涿县`（AND）、`(死，崩，薨)`（OR）等语法。
4. **AI 问答**（需配置 Key）：选择 agent_workflow 模式，直接提问，AI 会自己检索库内资料并作答。

## 六、局域网给别人用（可选）

- 用 manager.exe 选 **模式 2（服务器模式）** 启动；
- 系统绑定 `0.0.0.0`，同一局域网的人浏览器打开**启动窗口显示的局域网地址**（`http://你的电脑IP:20000/`）即可；
- 如果对方打不开，通常是 Windows 防火墙拦截：放行 `全文检索系统.exe`（或 20000 端口）即可。
- **多用户（新版）**：账号体系已内建在单个服务里，不需要再建多个端口/实例——
  1. 第一个人打开页面点右上角「注册」创建账号，**首个注册用户自动成为管理员**；
  2. 其他人同样注册后登录，各自拥有独立的库（**身份与数据库绑定**）；
  3. **游客（不登录）**看到的是「公共库」——所有游客公用的资料库，可共同维护；
  4. 登录后点公共库旁的「复制到我的库」，即可把公共库数据迁移一份到自己名下；
  5. 管理员可在命令行转移库所有权：`python main.py library transfer 库名 用户名`（设为公共库则写 `guest`）。

## 七、常见问题（FAQ）

### 1. 能不能只把 exe 文件拷出来单独运行？

**不能。** 这是打包成"目录模式"的程序：
- `全文检索系统.exe` 只是入口，运行时依赖旁边的 `_internal/` 文件夹（Python 运行库、本地模型全在里面，约 1.3GB）；
- 资料数据在 `data/` 文件夹里。

**必须把整个文件夹完整复制/拷贝**（U 盘、压缩包、网盘都行），然后整包拷到目标电脑再运行。只拷 exe 会报错或无法启动。

### 2. 换电脑 / 文件夹挪了位置，打不开怎么办？

程序会记录"数据目录"的绝对路径（在 `instances.json` 里）。挪位置后如果报错或找不到数据，这样做：

1. 先退出程序；
2. 删除文件夹里的 `instances.json` 和所有 `.pid_xxx` 文件（都是几行的配置/进程标记文件）；
3. 重新双击 `manager.exe` 启动，系统会自动把数据目录定位到当前文件夹的 `data/`。
4. （新版多用户的账号与库归属存在 `data/` 里的 `_users.json` / `_libraries.json`，删除 instances.json 不影响；旧版多实例的用户列表在 instances.json 中，删除会丢失。）

### 3. 提示"端口已被占用，自动切换"？

默认端口 20000，被占用时系统会自动改用 20001、20002…，看窗口提示的新地址即可。也可手动指定：`全文检索系统.exe --no-dialog --port 20000`。

### 4. 首次启动很慢 / 页面短暂无响应？

正常。首次要初始化本地语义模型并可能构建索引，约 5~10 分钟；之后就快了。

### 5. 想开机自动启动？

把 `manager.exe` 的快捷方式放进 Windows「启动」文件夹（`Win+R` 输入 `shell:startup` 回车），开机就会弹出窗口并自动运行——但窗口仍需保持打开。

### 6. 资料存在哪？怎么备份？

所有资料、索引、设置、聊天记录都在 `data/` 文件夹（多用户时每个用户一个数据目录）。**备份时把整个 `data/` 文件夹拷走即可**；恢复时放回原位。

### 7. 导入的 PDF 提示"图片型扫描件"？

说明这个 PDF 是扫描图片，没有文字层，系统读不出文字。需要先用文字识别工具（如 Adobe Acrobat、ABBYY、PaddleOCR）把它转成带文字层的 PDF 再导入。

## 八、目录速览（了解即可）

| 路径 | 作用 | 能否删 |
|------|------|--------|
| `manager.exe` | 多用户启动器 | 否 |
| `全文检索系统.exe` | 主程序 | 否 |
| `_internal/` | 运行库 + 内置语义模型 | **否** |
| `data/` | 资料库数据（库、索引、设置、账号、会话） | 否（含资料） |
| `data_zhangs/` 等 | 旧版多实例的独立数据区（新版多用户已内建，一般不再需要） | 视情况 |
| `instances.json` | 用户与端口配置 | 可删重建（见 FAQ 2） |
| `output/log/` | 运行日志（排障用） | 是 |
